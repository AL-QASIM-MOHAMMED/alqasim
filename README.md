# FITNE 💪

**FITNE** is an Android fitness application designed to help users improve their health and fitness through workout tracking, nutrition guidance, and health tools.

## 📱 Features

- **Login & Registration:** Create an account and log in securely.
- **Home:** View your fitness dashboard.
- **Workouts:** Explore different workout categories.
- **Nutrition:** Get nutrition information and meal ideas.
- **BMI Calculator:** Calculate your Body Mass Index.
- **Progress:** Track your fitness progress.
- **Profile:** View and manage your personal information.
- **Logout:** Securely log out of your account.

## 🛠️ Technologies Used

- Kotlin
- Android Studio
- Jetpack Compose
- Firebase Authentication
- Firebase Firestore

## 🚀 Getting Started

1. Clone or download this repository.
2. Open the project in Android Studio.
3. Connect your Firebase project.
4. Add your `google-services.json` file inside the `app` folder.
5. Sync Gradle.
6. Run the application on an Android emulator or device.

## 🎯 Project Goal

The goal of FITNE is to provide a simple and user-friendly fitness application that encourages people to build healthier habits and maintain an active lifestyle.
